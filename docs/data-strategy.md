# 数据策略：不依赖任何人回复

## 决策背景

原方案把 RivAIr 数据集（需向作者申请）当作主要验证数据。这个判断是错的 ——
跨国、无合作关系、学生身份三个不利因素叠加，数据共享请求的实际回复率很低，
即使回复也可能耗时一两个月。**不能把方案建立在别人的善意上。**

修正后的原则：**主路径必须完全由自己可控的数据构成。**

## 数据源分级

### 🟢 主路径：FloodNet（已验证可自动下载）

| 项目 | 值 |
|---|---|

| 获取 | Google Drive（ReDNetPlus 镜像，folder id `1leN9eWVQcvWDVYwNb2GCo5ML_wBEycWD`） |
| 规模 | **train 1445 / val 450 / test 448，影像与标签 100% 配对** |
| 平台 | **DJI Mavic Pro 无人机低空实拍**，约 200ft |
| 分辨率 | **4000×3000**，GSD 约 1.5cm |
| 类别 | 10 类，**water=5 已实测确认**，pool=8 |
| 划分 | **官方划分现成**，无需自建 |
| 许可 | CDLA-Permissive-1.0（**必须引用原文**） |
| 脚本 | `src/download_floodnet.py`（已跑通） |

**为什么它比 RivAIr 更适合作主路径**：

1. **立刻可得** —— 不需要等任何人
2. **官方划分** —— 不需要自己划分，也就不存在划分争议
3. **真无人机低空** —— 1.5cm GSD，镜面反光等低空特征真实存在
   （LoveDA 上反光维度失效，正是因为它是 0.3m 卫星正射影像）
4. **审稿人可核查** —— 公开基准，比自采数据说服力强

**它的局限（必须诚实面对）**：

- 灾后洪水场景，不是常态水利巡检 → 与你的应用场景有偏差
- 多地点采集，**帧间冗余度未知** —— 这是关键不确定性，见下方"首要验证项"
- 没有多条件分层元数据（无流态/天气标注）→ 贡献点 2 无法直接在其上做

### 🟡 必需：自采数据

不可替代。它提供 FloodNet 没有的东西：

- **中国水利场景**（渠道/水库/城市河道）
- **可控的采集条件** —— 同一水体在不同高度/角度/时段/光照下拍摄
- **贡献点 2 所需的多条件分层** —— 你可以主动设计条件矩阵
  （参考 RivAIr 论文 Table 1 的结构：流态 × 天气 × 高度）
- **连续视频帧** —— 冗余度可控且必然很高，这是方法的理想场景

## ⭐ 首要验证项：FloodNet 的冗余度

这是决定方法能否验证的关键，**必须在跑任何训练之前确认**。

LoveDA 实验失败的根本原因是冗余度太低（见 `experiment-log.md`）。
FloodNet 是多地点采集的灾后影像，**冗余度可能同样不足**。

诊断方法（数据下载完立刻跑）：

```bash
python -m src.diagnose_redundancy --root data/processed/floodnet --split train
```

`src/diagnose_redundancy.py` 已实现并用两个已知数据集校准过：

| 数据集 | 最近邻距离中位数 | 近重复(<0.05)占比 | 判定 |
|---|---|---|---|
| LoveDA（跨城市独立卫星影像） | 0.2461 | 1.5% | **低冗余** |
| 同条件重复采集（合成） | 0.0679 | 30.0% | **高冗余** |

判据阈值（据此校准）：
- 中位数 < 0.10 或近重复 > 20% → 高冗余，方法有发挥空间
- 中位数 < 0.18 或近重复 > 5% → 中等，需加大种子数与候选池
- 否则 → 低冗余，与 LoveDA 同类，**不要浪费算力跑完整实验**

**先诊断，再实验** —— 上次是跑完 8 组训练才发现数据不对，几分钟的诊断能替代数小时的算力。

### ⚠️ 一个已修正的指标陷阱

诊断脚本最初用**平均覆盖距离**评判 k-center，得出"k-center 比随机差 21%、
效应量 −2.61"的结论。这是**假阴性**：

k-center greedy 优化的是 **minimax 目标**（最小化**最差**覆盖距离），不是平均。
随机采样倾向落在样本密集区，平均距离自然更小，但会完全漏掉稀疏区域。

改用**最差覆盖距离**后结论反转：k-center 优于随机 **50–58%**，效应量 22.14。

教训：**评价指标必须与算法的优化目标一致**，否则会得出与事实相反的结论。
若按错误指标行事，会错误地放弃本来可用的数据和方法。

### 诊断的局限

它只衡量**特征空间**的可分辨性 —— 即策略是否选出了不同的子集。
覆盖度改进能否**转化为分割精度提升**，仍须实际训练验证。
所以效应量大是必要条件，不是充分条件。

这也解释了 LoveDA 上的现象：效应量 22.14（子集确实不同），
但训练精度无差异（0.7089 vs 0.7201）。子集不同 ≠ 精度更高。
真正的原因是冗余度低时，随机子集已经足够有代表性。

## 贡献点与数据源的对应关系

| 贡献点 | FloodNet | 东风渠 | 自采 |
|---|---|---|---|
| 1. 选帧策略（冗余感知 + 水体难度） | ✅ 若冗余度够 | ✅ | ✅ 最佳 |
| 2. 多条件预算分配 | ❌ 无条件元数据 | ❓ 未知 | ✅ **唯一可行来源** |
| 3. 标注预算基准 + 跨平台迁移 | ✅ | ✅ | ✅ |

**结论**：贡献点 2 基本只能靠自采数据。这进一步说明无人机手续是关键路径 ——
它卡住的不只是数据量，而是整个第二个贡献点。

如果时间线紧张，退路是：**只做贡献点 1 和 3，投 Q2**；
贡献点 2 留作后续工作或第二篇。这个决定可以等自采数据进度明确后再做。
